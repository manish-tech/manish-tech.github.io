AI · Side project

          
Conversational Product Search Agent

          
Problem: Keyword search fails when shoppers describe what they want in their own words.

          
Approach: A 7-node LangGraph pipeline. An LLM (Llama 3.3 on Groq) extracts structured filters, Qdrant runs vector and metadata search in one query, results are reranked by intent, and session state lets follow-ups like "under 2000" refine the previous search. Every node is traced in Langfuse.

          
Result: Natural-language, multi-turn product discovery over a catalog using RAG.

          
  • LangGraph
  • Qdrant
  • Groq
  • FastAPI
  • Langfuse
  • Python
